
# crish shell

Custom shell made with ❤️ and syntax highlighting.

It supports:

- Command execution
- Operators `;`, `&`, `|`, `<<`, `<<<`, `>>`, `>>>`
- File completion with `TAB`
- Command completion with `TAB`
- Syntax highlighting
- History navigation with UP and DOWN arrows

### Compilation

```sh
clang++ --std=c++20 -o crish crish.cpp
```
